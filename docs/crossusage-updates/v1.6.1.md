### Approved output contract

The full first-party contract, examples and implementation availability are in
the [JSON output reference](../json-output.md). Use the target metric names and
data shapes for chart/metadata/warning additions, explicit camelCase JSON field
names, and additive `currency` progress formatting for non-USD amounts. Preserve
existing fields and omit newly optional fields when absent. Preserve meaningful
values through CLI, HTTP and cached snapshots. Native label/type
changes also remain visible: Codex Credits becomes text and Reviews disappears;
Copilot Premium becomes Credits. Consumers relying on those labels/types must
adapt.

Keep empty-result validation and account error-suppression rules unchanged unless
separately approved. Upstream also converts an empty line list to an error; it
additionally preserves a warning. Supporting warnings does not require declaring
an empty successful metric result valid.

### Original override adaptation plan

- Codex: replace the obsolete loadAuth interception at the new orchestration
  boundary. Delegate the default account to native behavior. Route OpenCode
  accounts directly through their selected auth state, never the native fallback
  loop. Preserve exact-source reload/refresh/write-back, disabled-source policy,
  errors and all declared file subscriptions.
- Copilot: retain loadToken interception. Replace obsolete empty-object success
  fixtures with actual successful quotas and assert non-error metrics. Keep the
  no-data fixture as an explicit failure case.
- Verify the real transform/evaluate/discover/probe and daemon subscription
  lifecycle, not just manual wrapper calls. A surviving function name alone is
  insufficient evidence that the intended call path remains intercepted.
